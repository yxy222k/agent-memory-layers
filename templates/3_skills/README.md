# 第三层：操作技能（Procedural Skills）

本层存放「**怎么操作设备、软件、数据与办公工具**」的程序性记忆。

## 为什么独立成层
- 串口命令、`hdf5` 字段结构、PPT 导出规范在日常机理讨论或排故推理中不需要加载（平时 `0 token` 占用）。
- 每个子目录采用标准 `SKILL.md` 结构（含 `name` 与 `description` YAML 头），可直接被现代 Agent 框架按意图自动挂载，也可由人直接当速查手册查阅。

## 三条编写铁律
1. **密码/密钥零明文**：所有登录凭证、SSH Key、Git Token、Lark Webhook 密钥一律写环境变量名（如 `$LAB_GIT_TOKEN`）或系统钥匙串引用指令，**绝不写死明文**。
2. **具体内网 IP 外置**：可能随网络环境变化或涉密的设备 IP，优先指向本地 `.env`（已被 `.gitignore` 忽略）中的别名变量（如 `$SPEC_HOST_01`）。
3. **排故踩坑及时回补**：当 `4_anomalies/resolved/` 发现某次事故源于指令流控、数据格式截断或软件参数误用，离线蒸馏应直接更新对应 `SKILL.md` 的「常见坑」小节。
