# 技术报告撰写与对外脱敏规范

## 1. 结构与表达铁律
- **金字塔结论先行**：首页 / 首段直接给出核心判断与定量指标（注明版本与工况），不堆砌过程铺垫。
- **断言式标题（演示文稿）**：每页标题必须是可证伪的完整判断句（例：「切换线性稳压轨后闭环稳态抖动下降 82%，排除控制器参数发散」），禁用「测试数据分析」式空标题。
- **指标必带统计口径**：所有精度、噪声或漂移指标必须写明样本量、带宽/积分窗口、峰峰值（`p-p`）还是标准差（`1σ` / `3σ`）及对应硬件资产批次。

## 2. 对外交付材料脱敏自检单（导出前逐项核验）
- [ ] **核心算法保护**：已移除内部非线性补偿多项式阶数与系数、私有滤波器结构、内部源码符号及未公开标定原表。
- [ ] **供应链与定制件隐藏**：内部定制传感器/模块的具体供应商型号与内部序列号已替换为通用规格描述（如「24-bit 高速位移传感模块」）。
- [ ] **跨客户零泄露**：未混入其他客户代号、工装局部特征照片、产线节拍或良率数据。
- [ ] **截图净空检查**：软件截图中已遮蔽内网 IP、工程隐藏调试面板、用户名及本地私有仓库路径。
