# 第三层：操作技能（Procedural Skills）

本层存放「**如何安全连接设备、运行 CLI、归档数据与输出脱敏材料**」的程序性记忆。

## 为什么独立成层
- 总线协议、`.hdf5`/`.parquet` 字段结构、报告脱敏规范在纯机理推导或高层排故分析中无需常驻上下文（平时 `0 token` 占用）。
- 每个子目录采用通用 `SKILL.md` 结构（YAML 头包含 `name` 与触发场景 `description`），既可被现代 AI Agent 按任务意图自动挂载，也可供工程师直接查阅。

## 三条编写铁律
1. **凭证零明文**：所有登录密码、SSH 私钥、API Token、Webhook 密钥一律引用环境变量名（如 `$LAB_REPO_TOKEN`）或系统钥匙串指令，**绝不落盘明文**。
2. **可变地址外置**：随网络或台架变化的设备 IP、串口号与总线接口，统一指向本地 `.env`（已入 `.gitignore`）中的环境变量别名（如 `$CONTROLLER_HOST`、`$SENSOR_PORT`）。
3. **排故防呆回补**：当 `4_anomalies/resolved/` 确认某次事故源于指令时序、参数缺省值或数据格式截断时，离线蒸馏直接修补对应 `SKILL.md` 的「常见踩坑」小节。
