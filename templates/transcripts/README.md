# 事实底座（Transcripts & Sidecars）

原始记录层：实验室标定/样品测量伴生卡、现场工单流转、关键排故会话流水。**只追加，不改写。**

这一层是离线蒸馏核验「某条经验或模型假设到底对不对」的唯一基准。文档记录意图，原始记录记录事实；一旦被事后润色，纠错就会退化成互相引用。

## 命名与目录约定
- 公共/研发记录：`transcripts/YYYYMMDD-<lab|remote|sim>-<短标题>.md`
- 特定客户现场记录：放入 `tenants/<代号>/transcripts/`（通过目录边界配合 `scripts/search.sh` 实现物理检索隔离）

## 多模态与大体积数据怎么入库
测量装置照片、上位机软件截图、`.hdf5` 原始波形、`.pcap` 抓包文件不直接塞进 Git 文本库，而是按 `3_skills/data-schema/SKILL.md` 存入外部存储/LFS，并在此处落盘一份 **伴生索引卡（`_SIDECAR_TEMPLATE.md`）**。

## 外部记忆迁移原则
从旧笔记或各家 AI 助手历史记录导入时，**原样复制原文**并注明导入日期；历史记录中的「⚠ 已推翻」标记原样保留——那是认知演进的证据，不是垃圾。
