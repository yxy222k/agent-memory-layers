# 事实层

原始记录：现场会话、工单流转、实验过程、异常处理。**只追加，不改写。**

这一层是整理环节判断"这条笔记对不对"的唯一依据。一旦被润色过，纠错就退化成互相引用。

## 格式

`YYYYMMDD-<来源>-<短标题>.md`

```markdown
---
date: 2026-01-01
source: ticket | field | lab | remote
tenant: ____
version: ____
---
（原始记录，不做总结）
```

## 别人的记忆怎么导进来

从别的工具（各家 AI 助手的记忆目录）迁移时，**原样复制**，不要改写，
并在同目录放一个 README 说明来源和导入日期。结论要抽到 `notes/`，原文留在这里。

原文里常见的"⚠ 已推翻"标记要保留——那是知识演进的历史，不是矛盾。
