## 构建与协作原则（前沿大模型 + 多 Agent + 人工共审）
1. **模型选型**：文献发散调研、跨学科类比与数学建模由**最前沿旗舰模型**主导，不套死板八股，但结论入库必须经人工审阅。
2. **一人一页，禁止并发覆写**：多 Agent 协同调研时，每个子 Agent 独占一个专题 `.md` 文件，通过 `_RESEARCH_LOG.md` 同步进度与待查关键词，严禁多个 Agent 同时写同一张汇总表。
3. **接受第四层实测检验**：任何仿真模型都必须显式列出「理想化假设」；一旦 `4_anomalies/resolved/` 中的实测归因突破了某条假设，离线蒸馏必须回写本层的「失效边界」。
