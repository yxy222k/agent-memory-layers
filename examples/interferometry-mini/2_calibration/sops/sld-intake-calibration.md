# 1310nm SLD 光源入库标定规程

> 执行前必读：任一必检项或留证项缺失，禁止签发 `2_calibration/assets/` 档案。

## 一、 前置安全检查
- [ ] 核对管芯原厂出厂单极限电流，控制器硬件限流设在极限值的 `90%` 以下
- [ ] 接入 `#SPEC-01` 前串联 `>=10 dB` 固定光衰减器，确保满电流下峰值低于 `58,000 counts` `[ref: asset-SPEC-001]`
- [ ] 开启 TEC 温控预热满 `10 min`

## 二、 必测项目清单
- [ ] **全电流梯度中心波长漂移表**（`40 / 80 / 120 / 150 / 180 / 200 mA` 逐档记录质心波长、3dB 谱宽及 5 分钟抖动 $1\sigma$，标出稳定工作电流下限）← *由 `[ref: anom-20261112-001]` 反哺新增*
- [ ] 额定电流下连续 30 分钟输出光功率漂移（合格判据 `< 0.5%`）

## 三、 强制留证要求
- [ ] 光路连接与衰减器接入现场照片
- [ ] 各电流档位归一化光谱叠加截图
- [ ] 原始光谱序列存为 `.hdf5`，并在 `transcripts/` 建立伴生卡
