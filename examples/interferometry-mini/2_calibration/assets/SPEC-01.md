# 器件基线档案：1310nm 波段线阵光谱仪 `#SPEC-01`

## 安全红线与工作极值（每次调参必查）
| 指标 | 数值 / 阈值 | 备注 |
|---|---|---|
| 暗谱基线 (Dark counts) | `410 ± 12 counts` | `500 us` 积分档遮光实测 |
| **稳态饱和阈值** | **`58,000 counts`** | 超过后高强像素非线性压缩，包络质心失真 |
| **瞬时过载阈值（硬红线）** | **`64,500 counts` (16-bit 满量程前保护)** | **严禁裸光直通或高反镜未加衰减满电流照射** |
| 可用积分时间档位 | `50 us` / `100 us` / `200 us` / `500 us` / `1000 us` | 切档后必须重新扣除对应档位暗谱 |

- $\lambda(p) = 1265.104 + 0.08812 p - 1.42 \times 10^{-6} p^2\text{ (nm)}$（氖氩灯 + 可调谐激光器多点标定）
